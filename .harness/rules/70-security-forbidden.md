# 70 - 安全与禁止事项

## 安全

- 不读取、不输出、不提交任何密钥、token、用户数据。
- 不访问生产环境或线上服务。
- 不执行破坏性命令：`git reset --hard`、`git clean -fdx`、`git push --force`。
- 不安装未知来源插件或脚本。
- 不把项目代码/资源上传到未知服务。

## Godot 特有

- 不修改 `project.godot` 中的 Autoload、主场景、渲染设置，除非任务明确要求。
- 不修改 `export_presets.cfg`，除非任务是导出相关且用户明确要求。
- 不删除或重命名 `addons/` 中的测试框架文件。
- 不把 `res://` 路径硬编码到保存逻辑中；持久化数据只用 `user://`。

## 代码

- 禁止大范围重排场景节点、重命名无关文件。
- 禁止删除/跳过测试让 CI 通过。
- 禁止吞异常、留调试 `print`。
- 禁止无计划直接大改场景树。

## 违反处理

1. 停止。
2. 说明冲突点。
3. 给出替代方案。
4. 请求用户确认。
